# 🏥 Dental Alaniz - Backend API

API RESTful robusta y escalable construida para la gestión integral de una clínica dental. Este servicio maneja la autenticación segura, la persistencia de perfiles médicos y la lógica de negocio de un panel administrativo completo.

## 🚀 Tech Stack & Arquitectura

- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB (Mongoose)
- **Seguridad:** JWT (JSON Web Tokens) para autorización y autenticación.
- **AI-Augmented Development:** Lógica de rutas y refactorización optimizadas utilizando asistentes de Inteligencia Artificial (Cursor, Claude) para un código más limpio y eficiente.

## ⚙️ Core Features

- **Autenticación Segura:** Sistema de login y protección de rutas mediante middlewares y JWT.
- **Gestión de Base de Datos NoSQL:** Esquemas relacionales en MongoDB para vincular pacientes, doctores y citas.
- **Arquitectura Modular:** Separación estricta de responsabilidades (Rutas, Controladores, Modelos) siguiendo principios de diseño limpio para facilitar la escalabilidad.
- **Manejo de Errores:** Respuestas estandarizadas en formato JSON para el consumo eficiente desde el frontend.
